# Мемы и плакаты

Ничего редактировать не надо: просто кидай файлы в папки. Манифесты (`posters.json`,
`billboards.json`) собираются сами при `npm run dev` и `npm run build`, а на сайте всё
появляется после пуша в `main`.

## Плакаты — `posters/`

Вертикальные щиты вдоль тротуара в городе, промзоне и порту. Их около тридцати,
картинки раздаются по кругу.

- Формат: `jpg`, `jpeg`, `png`, `webp`, `avif`, `gif`.
- Пропорции: вертикальные, примерно 1:2 (например 1000×2000). Другие тоже подойдут,
  но растянутся под щит.
- Порядок: по имени файла. Хочешь задать очередь — начинай с номера: `01-…`, `02-…`.
- Пока папка пуста, на щитах рисуются процедурные плакаты с теми же надписями.

## Стенды — `billboards/`

Широкие экраны 16:9 на фасадах в городе, на мосту и в промзоне.

- Картинки: `jpg`, `png`, `webp`, `avif`, `gif`.
- Видео: `mp4`, `webm` — играет без звука и по кругу (иначе браузер не даст автозапуск).
- Пропорции 16:9, иначе растянется.

## Проверить, что подхватилось

```bash
npm run media
```

Напечатает, сколько нашлось треков, стендов и плакатов.
