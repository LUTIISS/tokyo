# Стенды с мемами

1. Скопируй картинки (jpg / png / webp) и ролики (mp4 / webm) в папку `billboards/`.
2. Перечисли их в `billboards.json`:

```json
{
  "items": [
    { "type": "image", "src": "/media/billboards/meme-01.jpg", "label": "Тот самый мем" },
    { "type": "video", "src": "/media/billboards/clip-01.mp4" },
    { "type": "image", "src": "/media/billboards/meme-02.png" }
  ]
}
```

- Стенды стоят вдоль проспекта (на фасадах), на мосту и в промзоне; элементы раздаются по кругу.
- Соотношение сторон экранов 16:9 — картинки лучше готовить под него, иначе растянутся.
- Видео играет без звука и по кругу (иначе браузер не даст автозапуск).
- Сами файлы в git не попадают (см. `.gitignore`), только `billboards.json`.
