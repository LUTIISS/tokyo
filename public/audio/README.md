# Музыка

Ничего редактировать не надо: кидай файлы в `tracks/`. Манифест `tracks.json` собирается
сам при `npm run dev` и `npm run build`.

- Форматы: `mp3`, `ogg`, `m4a`, `opus`, `wav`, `flac`.
- Порядок в плейлисте — по имени файла. Хочешь задать очередь: `01-…`, `02-…`.
- Название в HUD берётся из имени файла: `01 - Teriyaki Boyz - Tokyo Drift.mp3`
  покажется как «Teriyaki Boyz — Tokyo Drift».
- Файл, имя которого начинается на **`finale`** (например `finale.mp3`), становится
  финальной темой: включается на рассвете после победы над Ваисовым и играет по кругу.
- В игре: `N` — следующий трек, `M` — выключить звук.

Проверить, что подхватилось:

```bash
npm run media
```
