# TOKYO NIGHT DRIFT — Toyota Mark II

Браузерная 3D-игра в духе [Slow Roads](https://slowroads.io), но про ночной Токио, неон и дрифт.
Белая Toyota Mark II (JZX100), персонаж, который к ней подходит и садится, петля трассы через
город, мост, горный перевал и порт, стенды с мемами, квест, мастерская с тюнингом в духе Gran Turismo,
база Ваисова, освобождение аниме-девочек, рассвет и сакура.

Всё процедурное: никаких моделей и текстур с диска. Музыка и мемы подкладываются в `public/`.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # прод-сборка в dist/
npm run preview    # посмотреть прод-сборку
npm run typecheck  # проверка типов
```

Нужен Node 22+. Открывать лучше в Chrome / Edge (WebGL 2, bloom).

## Деплой

Игра выкладывается на GitHub Pages автоматически: workflow `.github/workflows/deploy.yml`
собирает проект при каждом пуше в `main` или в ветку `claude/**` и кладёт сборку в ветку `gh-pages`.

Адрес: **https://lutiiss.github.io/tokyo/**

Ветка `gh-pages` со сборкой уже есть, репозиторий публичный. Единственное, что GitHub не даёт сделать
из автоматики, — выбрать источник Pages. Один раз, руками:

Settings → Pages → Build and deployment → Source: **Deploy from a branch** → ветка **gh-pages**, папка `/ (root)` → Save.

Через минуту адрес заработает; дальше каждая сборка обновляет его автоматически, а workflow в конце
сам проверяет, что сайт отвечает (шаг «Check site» во вкладке Actions).

Локальная сборка (`npm run build`) собирается для корня сайта; для подпапки задаётся переменная
`BASE_PATH=/tokyo/` (workflow делает это сам).

## Управление

| Клавиша | Действие |
| --- | --- |
| `W A S D` / стрелки | Ходить / ехать (руль, газ, тормоз, задний ход) |
| `Space` | Ручник — срывает в занос |
| `Shift` | Бег пешком / **флюгегехаймен** + нитро (после апгрейда) |
| `E` | Сесть в машину · начать квест · открыть тюнинг · штурм · выйти из машины |
| `C` | Камера: ближняя / дальняя / капот |
| `Tab` | Большая карта трассы (мини-карта с расстоянием до цели всегда в углу) |
| `R` | Поставить машину на трассу |
| `N` / `M` | Следующий трек / звук |
| `B` | Bloom вкл/выкл (если тормозит) |
| `H` | Скрыть/показать подсказки |
| `Esc` | Пауза / закрыть меню |

Управление персонажем — относительно камеры. В меню и диалогах работает мышь, `Enter` подтверждает, `Esc` закрывает.

## Сюжетная петля (что уже работает)

1. **Старт.** Персонаж стоит на тротуаре у припаркованной Mark II. Подходишь — `E` — дверь открывается,
   он садится, дверь закрывается, заводится двигатель.
2. **Едешь по петле** (≈4,3 км): проспект Сибуя со стендами на фасадах → мост через залив → горный
   перевал со шпильками (тут дрифт) → смотровая площадка → промзона → порт → обратно в город.
   На стендах — мемы и ролики из `public/media/`, в машине играет музыка из `public/audio/`.
3. **Квест** на смотровой площадке (розовый маяк за перевалом). Сейчас — заглушка: подъехал, `E`,
   получил **¥100 000**. Место под настоящий квест: `src/quests/Quest.ts`.
4. **Мастерская** в промзоне: ворота поднимаются при подъезде, внутри — `E` — меню тюнинга.
   Двигатель, турбо, шины, спойлер, цвет неона — бесплатно. **Флюгегехаймен** стоит ровно ¥100 000:
   чёрная продолговатая штука в капоте, по `Shift` выезжает и очень быстро долбит вперёд-назад.
5. **База Ваисова** в порту. С флюгегехайменом — `E` перед воротами — «Победить Ваисова»:
   ворота снесены, во двор выходит сам Ваисов. Разгоняешься, держишь `Shift` и таранишь его
   флюгегехайменом — пять попаданий, и он падает. Клетка открывается, девочки свободны.
6. **Финал.** Ночь сменяется днём (~30 с), деревья зацветают, падают лепестки, включается финальный трек.
   Дальше — свободная езда, прогресс сохраняется в `localStorage`.

## Куда класть музыку и мемы

- **Музыка:** файлы в `public/audio/tracks/`, список в `public/audio/tracks.json`
  (см. `public/audio/README.md`). Есть слот `finale` для трека на рассвет.
- **Мемы и ролики** (широкие экраны 16:9): файлы в `public/media/billboards/`, список в
  `public/media/billboards.json`. Картинки — jpg/png/webp, видео — mp4/webm (без звука, по кругу).
- **Плакаты** (вертикальные щиты вдоль тротуара, ~1:2): файлы в `public/media/posters/`, список в
  `public/media/posters.json`. Пока их нет, на щитах рисуются процедурные версии тех же плакатов.

Сами медиа-файлы в git не попадают (`.gitignore`), только манифесты.

## Структура кода

```
src/
  main.ts                 точка входа
  config.ts               все настройки: трасса, машина, экономика, цвета неона
  core/Game.ts            цикл, машина состояний (ходьба → посадка → езда → гараж/квест/босс/финал)
  core/GameState.ts       иены, апгрейды, флаги сюжета, сохранение
  core/Input.ts           клавиатура (по кодам клавиш — работает в русской раскладке)
  world/World.ts          сборка мира и запросы «что под колёсами»
  world/Terrain.ts        ландшафт: залив, горы, выравнивание под дорогу
  world/Track.ts          сплайн-петля, меш дороги, тротуары, отбойники, мост
  world/City.ts           здания с окнами, неоновые вывески, скайлайн, телебашня
  world/Props.ts          фонари, сакура, тории, автоматы, контейнеры, прожекторы
  world/Billboards.ts     стенды: манифест, картинки, видео, заглушки
  world/Zones.ts          смотровая (квест), мастерская, база Ваисова
  world/Sky.ts            небо, звёзды, луна/солнце, свет, туман, день/ночь
  world/Sakura.ts         лепестки
  entities/CarModel.ts    процедурная Mark II
  entities/CarPhysics.ts  аркадная физика с дрифтом
  entities/Car.ts         машина целиком: модель + физика + эффекты + апгрейды
  entities/Player.ts      персонаж
  camera/CameraRig.ts     режимы камеры и перелёты
  audio/AudioManager.ts   плейлист, синтез двигателя и шин, SFX
  ui/HUD.ts, GarageMenu.ts, Overlays.ts
  quests/Quest.ts         интерфейс квеста и заглушка
```

Параметры, которые чаще всего хочется крутить, лежат в `src/config.ts`: контрольные точки трассы
(`TRACK_POINTS`), ширина дороги, физика машины (`CAR`), награда и цена апгрейда (`ECONOMY`), цвета неона.
